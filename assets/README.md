# Assets Specification / 视觉资源规范

本目录用于存放 `DieDieFlip`（叠叠翻棋）的前端视觉资产（游戏横幅、对弈动图与截图）。

## 1. 游戏主视觉横幅 (`hero-banner.png`)
- **文件路径**: `assets/hero-banner.png`
- **建议比例**: 1200 x 420 (宽屏横幅)
- **推荐风格**: 
  - 新中式水墨棋盘、传统木质棋子、立体堆叠层次阴影与金红对决氛围。
  - 主文案：`叠叠翻棋 • DieDieFlip • 原创新中式象棋翻棋独立博弈`
- **生成建议 (Midjourney/DALL-E)**:
  > *Cinematic hero banner for a Chinese chess variant tabletop game, high-end Chinese ink wash and dark walnut wood texture, 3D stacked wooden chess pieces with carved traditional calligraphy (車 馬 砲), dynamic game board perspective, subtle gold leaf accents, dramatic studio rim lighting, 8k resolution, minimalist modern Chinese aesthetic.*

## 2. 对弈实况动图演示 (`gameplay-demo.gif`)
- **文件路径**: `assets/gameplay-demo.gif`
- **建议比例**: 1280 x 720 (16:9)
- **推荐内容**: 
  - 录制浏览器中本地双人同屏对弈过程：点暗格翻棋、选中棋子叠放、吃子整叠入库存、坐标记谱面板实时滚动以及取层计数条交互。
