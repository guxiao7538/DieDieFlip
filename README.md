# 叠叠翻棋 (DieDieFlip)

基于中国象棋棋具的双人翻棋变体游戏:4×8 半盘 32 棋暗置,翻棋定阵营,以**翻/移/放/叠/取**五种操作对弈,叠层与层数机制决定攻防。本地双人同屏,纯前端,无后端。

## 玩法规则

详见 [叠叠翻棋规则.md](叠叠翻棋规则.md)。要点:

- 翻第一枚棋定阵营,双方严格交替行动
- 五种操作:翻棋、移动、放置、叠层、取层(每回合一种)
- 走法:车直线 / 马斜一格 / 炮平移+隔一炮架打吃 / 其余横竖一格
- 吃子无等级,看**层数**:层数多者可吃少者,同层互吃;叠层被吃整叠入库存
- 胜利:吃光对方全部棋子(含库存),或对方无合法操作;可协商和局、投降、悔一步

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm run test     # 规则引擎单测(vitest)
npm run build    # 类型检查 + 构建到 dist/
```

## 技术架构

- **规则引擎** `src/game/`:纯 TypeScript,零 DOM 依赖,可独立单测、可被 Capacitor 套壳复用
- **展示层** `src/ui/`:原生 DOM 渲染 + 上下文智能交互(点暗格翻棋、点己方棋移动、点库存棋放置/叠层、取层角标)
- 状态不可变,悔一步依赖状态历史栈

## 版本

采用语义化版本(MAJOR.MINOR.PATCH):

- **MAJOR**:规则或架构不兼容变更
- **MINOR**:新功能(可选规则 A/B、AI、在线对战、音效等)
- **PATCH**:bug 修复与体验优化

| 版本 | 说明 |
