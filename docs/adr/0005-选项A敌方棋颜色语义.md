# ADR-0005 — 选项A敌方棋颜色语义(颜色随子走,顶层色即归属)

规则七选项 A 原文"执行后最上层仍须为己方色"存在自相矛盾:敌方色棋子的叠层/放置必然使其成为执行后的最上层,若按字面要求顶层保持己方色,选项 A 的任何操作都非法,该玩法等于不存在。裁决:选项 A 下敌方色棋子**保留实际颜色**使用——放置仅限空格,叠层目标仍须己方同类叠层(ADR-0004 不变);执行后顶层为该敌方棋的实际颜色,按"顶层色即归属"惯例,该格从此视为对方叠层(对方可移动/叠层/取层)。这赋予选项 A 真实战术价值:为自家炮造炮架、喂目标子、向对方让子调拨子力。若未来改为"顶层须己方色"读法,改动点为 `moves.ts` 叠层/放置合法性中按 `useEnemyForPlace` 拒绝敌方色棋。
