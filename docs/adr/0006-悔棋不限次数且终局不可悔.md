# ADR-0006 — 悔棋不限次数,终局后不可悔

规则文档原文"悔一步……最多一步"与实现不符:引擎 history 存全量状态快照,UI 允许连续悔棋。裁决维持实现——本地双人同屏信息全透明(暗格除外,而翻出的子已双方共见,悔棋不泄露新信息),"最多一步"没有信息论依据;悔棋不限次数。终局(分出胜负或和局成立)后不可悔棋,UI 禁用按钮(此前和局后仍可悔、投降后不可悔,口径不一,统一为终局即封盘,想继续可悔至终局前再议)。改动点:`panels.ts` 悔棋按钮 disabled 条件;`规则.md`/`CONTEXT.md` 删除"最多一步"表述。若未来改在线对战,翻子是否可悔须重新裁决(信息隐藏问题才真实存在,参考 boardgame.io 的 per-move undoable 惯例)。
